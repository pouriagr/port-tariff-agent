# data/

Runtime storage for ingested tariff documents. Everything here is generated by
`port-tariff ingest`, except `raw/`. Files marked *tracked* below are committed;
the rest are git-ignored and rebuilt on demand.

```
data/
  raw/                      # tracked: source PDFs shipped with the repo
  documents.json            # tracked: registry, one row per ingested document
  <document_hash>/
    source.pdf              # copy of the ingested file
    pages/                  # one Markdown file per PDF page (LLM transcription cache)
    tariff.md               # all pages joined, with page markers
    tariff_index.json       # tracked: flat list of numbered sections with their text
    charges.json            # tracked: catalog of payable charges found in the document
    classification.jsonl    # one row per classified section (cache behind charges.json)
    profile.json            # tracked: document profile (issuer, title, currency, validity)
    manifest.json           # tracked: per step, prompt version, prompt sha, model, times
```

## Which files are committed (ADR-022)

`documents.json`, `tariff_index.json`, `charges.json`, `profile.json` and `manifest.json`
are everything the query phase reads, about 120 KB. Committing them lets the validation suite run in CI
with no API key and no PDF ingestion, and pins the exact bytes the accuracy report was
measured against. `manifest.json` carries its own provenance: which prompt version, which
prompt sha and which model produced the other three.

What stays out: `source.pdf` (byte-identical to the copy in `raw/`), `tariff.md` and
`pages/` (the transcription cache, not read at query time), and `classification.jsonl`
(the cache behind `charges.json`). Delete any of them and `port-tariff ingest` rebuilds
it; the committed artifacts are skipped because the registry row already exists.

`<document_hash>` is the SHA-256 of the PDF bytes. A new edition of a tariff
book gets a new hash, a new folder and a new row in `documents.json`; old rows
are never overwritten. See `docs/spec/ingestion.md` for the schemas.
