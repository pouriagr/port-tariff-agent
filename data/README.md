# data/

Runtime storage for ingested tariff documents. Everything here except `raw/`
is generated by `port-tariff ingest` and is git-ignored.

```
data/
  raw/                      # source PDFs shipped with the repo
  documents.json            # registry: one row per ingested document
  <document_hash>/
    pages/                  # one Markdown file per PDF page (LLM transcription cache)
    tariff.md               # all pages joined, with page markers
    tariff_index.json       # flat list of numbered sections with their text
    charges.json            # catalog of payable charges discovered in the document
```

`<document_hash>` is the SHA-256 of the PDF bytes. A new edition of a tariff
book gets a new hash, a new folder and a new row in `documents.json`; old rows
are never overwritten. See `docs/spec/ingestion.md` for the schemas.
